# .github

이 계정의 저장소가 같이 쓰는 [기본 커뮤니티 파일](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)입니다.

| 파일 | 내용 |
| --- | --- |
| [CONTRIBUTING.md](CONTRIBUTING.md) | 외부 기여자를 위한 안내 |
| [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE) | 이슈 양식(빈 이슈도 작성 가능) |

같은 종류의 파일이 없는 저장소에 적용됩니다. 저장소에 이슈 양식이나 설정이 하나라도 있으면 여기의 이슈 양식은 모두 적용되지 않습니다. 이 파일들은 각 저장소의 클론에 포함되지 않습니다.
